## Détail

### La console contre le journal

- *Quand* : le lendemain de la passe, quand la console a reçu la journée.
- *Comment* : Google Cloud, *APIs & Services* → *Places API (New)* → *Metrics*, méthode
  `SearchNearby`, sur novembre. Côté base, en lecture seule :

  ```sql
  begin read only;
  select sum(calls_made) from sweep_execution where period = '2026-11';
  commit;
  ```

- *Attendu* : la console ne compte pas plus que le journal, environ 450. Aucune autre méthode de
  Places API n'est utilisée : elles sont plafonnées à 0 par jour.
- *Sinon* : quelque chose dépense hors du balayage — un autre projet sur le même compte de
  facturation, ou une clé utilisée ailleurs. Aucun `--go` avant d'avoir compris.
